# Interview signaling fixture scope

Run `npm run typecheck` and `npm test` with the package's supported Node 24 runtime. Tests use the actual Worker export, SQLite-backed Durable Object, accepted WebSocket pairs, object eviction/hibernation and alarm handler inside workerd. The operator, invite and TURN credentials are test fixtures. Every outbound provider `fetch` is intercepted; an unmatched call throws instead of reaching a real provider. Create mocked `Response` bodies inside the mock callback so they belong to the requesting Durable Object's I/O context.

The 18 tests cover operator/origin/body gates; hash-only capability storage and no SDP persistence; host/guest authority; admission, stage and signal generation gates; capacity and lock; one active generation per invite; replacement host versus genuine host loss; hibernation recovery; revocation, expiration and alarm end; payload/rate limits with a healthy peer; sanitized TURN configuration, port validation, provider errors and refresh rate limits; concurrent invite ceiling; held TURN replies after revoke, rejoin, end or expiry; and a stalled receiver exhausting32 outgoing delivery credits while the healthy host remains responsive. `test/env.d.ts` loads the installed Vitest plugin's runtime test types.

This validates local signaling and request lifecycle software. It does not qualify Safari/Chrome/mobile media, native StreamMac host capture, audio alignment/ISO recording/mix-minus, real TURN credentials or relay-only networks, long-call reconnect, measured guest capacity, or sustained slow-consumer/fanout load on a deployed service. Host-agreed Program/recording flags are protocol metadata and are not evidence of native broadcasting or recording.

The fixture APIs follow the current [Workers test APIs](https://developers.cloudflare.com/workers/testing/vitest-integration/test-apis/) and [Durable Object WebSocket guidance](https://developers.cloudflare.com/durable-objects/best-practices/websockets/), verified on 2026-10-02. No deployment or external provider mutation is performed.
