# Restream confidential authorization service

Companion to the native public client; see [the full contract](../../apple/docs/RESTREAM_AUTH_BROKER.md). This service is not deployed or configured by the repository.

Use Node24.15+ (24.x), `npm ci`, `npm run typegen`, `npm run typecheck`, `npm test`, and `npm run build` (Wrangler dry-run only). The tests use a Miniflare outbound provider fixture and synthetic credentials; they make no real OAuth request. `PUBLIC_ORIGIN` and `RESTREAM_CLIENT_ID` are deliberately blank, and the server fails closed without its `RESTREAM_CLIENT_SECRET` secret binding. Do not put confidential credentials in vars, native settings, source, logs or URLs. Operator registration, secret provisioning, service deployment and actual consent require a separate authorized rollout. Configure the registered Restream redirect to the deployed HTTPS origin plus `/oauth/callback`.

The server retains provider refresh credentials in [encrypted-at-rest Durable Object storage](https://developers.cloudflare.com/durable-objects/reference/data-security/); native receives only actual access/scopes and an opaque broker credential. Pending states expire after10min; completed sessions after30days. A persistent in-flight rotation with no live task fails closed. Native sign-out deletes local authority and best-effort retires its broker session; actual provider grant revocation uses provider account controls. Default request logs are disabled, but infrastructure operators must retain the same exclusion for callback codes and authorization headers in any added tracing. The public native authorization entry requires no embedded app secret; its IP limiter is a basic abuse bound, not a deployment qualification or universal rate guarantee.
