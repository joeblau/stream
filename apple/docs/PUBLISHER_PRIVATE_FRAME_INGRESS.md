# Publisher private frame ingress

Publishing registers one compositor delivery domain per independent raw destination, or one per actual fixed H.264/AAC encoder group and canvas. The former controller-lifetime Program AsyncStream and raw-video fanout are removed. The fanout still distributes the common Program audio and the existing immutable compressed packets.

The synchronous manual/managed publish gate reserves actual bounded BGRA storage before calling a publisher factory. Manual Go Live reserves its immediate manual destinations in one atomic batch. Managed destinations awaiting review reserve at their later one-use synchronous publish gate. A returned adapter that disagrees with the selected shared-input capability fails locally; it does not fall back to an unadmitted raw encoder. The default shipping RTMP/RTMPS/SRT adapters support the prospective shared key; WHIP and profiles faster than their declared source remain separate raw paths.

Every raw destination receives its own six-buffer private bank. A shared encoder's six-buffer bank is its existing target conversion pool: the sealed broker completes the same aspect-fit, black backing and sRGB conversion before the encoder's two-item prepared queue. There is no extra full-size ingress copy for the shared path. Existing source cadence/PTS, downsampling phase, four accepted VT frames, keyframe spacing, AAC pipeline, compressed object identity and downstream GOP recovery remain unchanged.

Startup waits for authoritative Program/Secondary geometry commands, then the Engine's source/private-bank installation acknowledgment, before invoking `publisher.start`. Existing geometry commands and stop share ordered task chains. The output plan never overwrites a newer geometry or retries bank preparation by polling. Runtime generation and current lock/rehearsal/destination authority are checked after suspension. Managed starts also capture the reviewed account revision and exact context at synchronous handoff, then recheck those local values for the exact connecting runtime immediately before `publisher.start`. This adds no provider/vault requests and does not revoke already-started outputs after a later account revision. Stop revokes the owned cancellation ticket immediately; late cleanup addresses only its captured registration.

Source claims belong to the Engine after acknowledgment. An endpoint retires only its own private claim; one endpoint cannot close a source bank used by its siblings. Shared group members retain one ingress owner, and repeated joins release redundant admission claims. Process-wide accounting quarantines exposed banks across fresh sessions; stop/append completion is not evidence that opaque retained pixel/surface aliases disappeared. A full private bank drops only that domain's transfer. Optional diagnostic fields distinguish transfer drops, private-capacity drops and conversion failures from publisher connection failure.

## Owned validation

`run_publisher_private_ingress_harness.zsh` uses actual controller, budget/coordinator, broker and converter code with inert Publisher actors. One actor retains every private sample after `appendVideo` returns. Its bank fills at six while a healthy sibling receives all 20 source frames. Assertions compare corresponding live source/private/peer surface identities, require local capacity-drop receipts, and verify a restarted session never changes old retained pixels or reuses its exposed bank. A held installation proves no publisher starts before ACK, after synchronous cancellation, or after captured startup authority is revoked. The latter test also changes an already-started peer's startup authority and requires that peer to remain live and receive its next frame. An invalid atomic batch crosses no factory; an injected shared-capability mismatch refunds its never-exposed reservation. A distinct-timescale case preserves both original PTS even when their integer CMTime values coincide.

The existing destination fixture declares its actual synthetic input geometry and waits for the real start boundary before injecting source frames. Its bounded transport mailbox plus broker intent drops still account for the full unconsumed burst; exact newest-two transport behavior and independent lifecycle assertions remain.

The shared encoder fixture can compile with `STREAM_PUBLISHER_CODEC_ONLY`, excluding transport implementations and network calls while retaining actual VT/AAC, compressed identity/bytes/PTS, keyframe, cadence, file decode and finish assertions. It also performs 35 joins/leaves on one surviving group. Invalid audio-as-video is first checked as an ordinary broker conversion rejection; a separate `STREAM_NATIVE_VALIDATION` prepared-input seam exercises the actual codec's defensive failure/finalization guards without injecting an original compositor image. Normal builds have no such direct prepared-input method.

These proofs establish the owned software boundaries. They do not qualify hardware throughput, a new physical memory maximum, provider acceptance, real network transport, or physical playback. The explicit AVAudioFile offline PCM decoder mode is reported separately from the default AVAssetReader PCM path.
