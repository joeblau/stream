# Media playback retirement

Transport Stop parks a source for reuse. Terminal `MediaSourcePlayback.shutdown()` retires it: invalidate the pending asset-load generation, detach callbacks, pause/release players, remove observers, cancel readers, and release the successful security-scope acquisition exactly once. A failed or superseded asynchronous load releases its locally owned scope instead of installing a player. Relink compares the originally loaded bookmark with the current payload before committing metadata. Queued AVPlayer and animated-image callbacks retain their generation and cannot update a replacement file.

Soundboard voice retirement uses terminal shutdown before removing mixer demand. A separate delivery gate drains an already executing PCM callback before shutdown returns, without holding the playback lock. A captured but not yet executing callback cannot recreate a removed mixer channel after retirement. Normal transport Pause/Stop keeps its existing reusable behavior.

Run `MEDIA_LIFECYCLE_FRAMEWORKS=/path/to/Build/Products/Debug zsh apple/scripts/run_media_playback_lifecycle_harness.zsh` with matching built StreamCore products. The bounded native fixture loads owned WAV assets through actual AVAsset metadata, AVPlayer and AVAssetReader, decodes a two-frame GIF, suspends metadata completion, retains actual queued callbacks and decoded PCM, and tests terminal retirement, relink, deinit and in-flight delivery drain. Its generated source copy replaces only the external bookmark/grant boundary with counted fixture-owned file access and inserts a controlled post-metadata suspension. Counted ownership is not an actual sandbox/TCC grant qualification. No microphone/camera/screen capture or device/system changes are performed.
