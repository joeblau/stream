# Native control-row style diagnostics

The original 50084bb Intel CI invocation failed the existing assertion, “The owned native style must remain selected.” It did not record the requested style, row kind, text size or native view identity, and buffered output did not preserve preceding case results. That observation does not establish whether AppKit reset or refused a style, SwiftUI replaced the native container, or another layout transition occurred. The cause remains unknown.

The fixture now records unbuffered JSON before style assignment, immediately afterward, after layout and intrinsic measurement, before the style assertion, and after trailing scrolling and wide layout. Records include requested, actual and preferred styles; captured and freshly discovered native scroll/document identities; scroller classes and accessory state; geometry; and whether the owned window is visible or key. It observes public preferred-style and application-finished-launching notification names without reading their objects or changing application startup. Public `NSApp.isRunning` is recorded. No settings are changed.

All 11 original assertion expressions remain byte-identical, including style persistence, exact intrinsic height, complete vertical exposure, 320/844-point viewports and reaching the trailing controls. The same 40 row/style cases cover 11 through 20 points. The 60-second compile and 90-second runtime limits, 50ms layout settling and prohibited application policy remain unchanged. No retry, skip, style substitution or production change was added.

One local invocation compiled successfully and passed all 40 cases on macOS 27.2. Its 280 layout records retained the same live scroll and document identities, with no style mismatch after assignment and no visible or key window. The preferred style was legacy. `NSApp.isRunning` remained false, and no preferred-style or finished-launching notification was observed. These facts do not establish the original Intel cause or a need to change startup. No further native attempt was made.

Run the unchanged matrix with `python3 scripts/test_studio_control_rows.py` from `apple`. Durable results are retained under `apple/build/studio-control-rows-validation/artifacts/invocation-UUID`, including source snapshots and hashes, generated Swift, binary, compile/runtime logs, `result.json` and `failed-phase.json`. An optional `--artifact-dir NEW_PATH` selects a fresh owned destination. Child output goes directly to a file; CI echo occurs after the child completes. Failure and timeout metadata are written in `finally`.

The dated JSON receipt binds the original Intel log and this first local outcome. Hosted Intel evidence remains pending. This component-layout fixture does not qualify the full workspace, accessibility delivery, focus, visual contrast, media or devices.
