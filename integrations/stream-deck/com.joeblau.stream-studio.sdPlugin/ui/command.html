Connecting to Stream Deck…

The token is sent once to the native Keychain helper. It is never saved in Stream Deck action settings or exported profiles. Revoke it in Stream Studio when removing this controller.
Rotate changes the native channel level. Press/tap toggles mute; hold the touch strip to reset to 100% unity gain. The display follows authoritative studio state.

A binding stays with its resource UUID after rename/reorder. Missing resources and project changes require an explicit new selection. A selector dial browses without activating; press or tap to run the selected command. Feedback follows the studio.
