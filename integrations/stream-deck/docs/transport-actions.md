# Scene and transport actions

The Command key discovers the current native studio catalog. **Select Scene** stages Preview. **Run Scene** takes that saved scene through the shared scene transition, sound, audio, media, and PTZ hooks; when that scene is already staged it takes the current staged edits. **Next/Previous Scene** select adjacent scenes. Take, Revert, Preview/Program editing, and Direct Live editing retain their native behavior. Scene UUIDs survive rename/reorder; deleting a resource removes its commands.

**Start Stream** starts enabled destinations through the same native Go Live path. **Stop All Local Publishing** disconnects local publishing and cancels pending managed starts; it does not claim to complete a provider event. **End All Remote Events and Local Outputs…** opens a native studio confirmation for captured current sessions. Independent recording continues.

Each saved destination has explicit **Start**, **Stop Local**, **End Remote…**, **End Both…**, and **Review Remote** variants. Start and Stop can be placed in multi-actions without toggling an unknown state. Start still validates the current encoder/canvas budget, lock/rehearsal state, and connection. Managed starts open the native event/bound-stream review; keys cannot provide its consent or bypass provider authorization. Stop also cancels that destination's pending managed start review.

The optional exact-event commands include a hash of the public provider/channel/event identity in their stable IDs. Renaming a destination preserves these IDs; changing the selected event produces different IDs. Commands captured for a previous event reject rather than start a replacement event. A running publishing session retains its captured routing even when the saved destination is edited for a future start. End actions use that session's routing. Destination-only bindings intentionally follow that saved destination's current selection.

End Remote and End Both request the same deliberate native confirmation as studio ending controls. The dialog names the captured destinations and provider events. A changed session/binding invalidates confirmation. Disconnecting the requesting controller retires its unconfirmed review; confirmed provider work is never replayed on reconnect or silently undone. Review Remote performs a fresh provider read without completing it. Unsupported remote completion stays unavailable or produces an explicit unsupported receipt during End Both; local stop cannot manufacture a remote receipt.

Feedback distinguishes **PVW**, **PGM**, connecting/live/reconnecting/stopping/failed, native managed-start review, **CONFIRM IN STUDIO**, pending ending, and confirmed or uncertain remote receipts. **REMOTE ENDED** comes only from a matching provider completion receipt, while local delivery may still be Live. Recording keys show native preparing/recording/paused/stopping/failed state and **REC IN n** countdown; Start, Stop, Pause, Resume, and New File use the independent recording writer. No key press optimistically invents publication or recording state.

Validation includes the bundled Elgato SDK against isolated WebSocket/TCP services, native loopback authentication/dispatch/disconnect tests, the actual dispatcher source graph, and the ending coordinator's provider requests and stale-session fences. `STREAM_DECK_VALIDATE_TRANSPORT=1 apple/scripts/run_studio_deck_native_harness.zsh` additionally runs selected Start/Stop against an owned localhost RTMP FFmpeg receiver and the independent real recording writer. That generated tool denies physical microphone capture and substitutes a no-op Keychain; publishers, composition, audio mixing, and recording writers are shipping implementations.

Large resource sets use the protocol's negotiated `responseChunks: true` authentication extension. The host sends at most 64 KiB per JSON frame and carries the complete original response in 24 KiB byte chunks, identified by transfer/session and snapshot revision. Clients assemble and validate the whole response before exposing its resource maps. A newer incomplete revision shows **Updating State** and prevents execution against stale receipts; superseded event transfers and disconnected sessions are retired. The aggregate response budget is 16 MiB with at most eight incomplete transfers; exceeding it produces an explicit protocol error, never a truncated map. The bundled Python status adapter and command-line client use the same framing contract. Older clients continue receiving ordinary small frames and receive an explicit update-required error for a larger project.
